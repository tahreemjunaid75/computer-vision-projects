# Computer Vision Course Projects

A collection of practical projects spanning image segmentation, object detection, transfer learning, deep learning, classical computer vision, motion, stereo depth, and digital image processing.

## Repository Structure

The repository contains nine category folders and thirteen notebook projects. Some categories contain multiple project subfolders.

| Category | Focus |
|---|---|
| `01-image-segmentation/` | Semantic and instance segmentation |
| `02-object-detection/` | Object localization and detection |
| `03-transfer-learning/` | Pretrained CNN transfer learning |
| `04-image-classification/` | MNIST classification models |
| `05-deep-learning-with-tensorflow-keras/` | CNN architecture comparisons |
| `06-classical-cv/` | Geometry, Hough transforms, edges, panorama |
| `07-motion-estimation/` | Motion and optical flow |
| `08-stereo-and-depth-estimation/` | Stereo disparity and depth |
| `09-digital-image-processing-fundamentals/` | Image processing fundamentals |

## Tech Stack

- **Language:** Python 3.10+
- **Computer vision:** OpenCV, Ultralytics YOLO11, scikit-image
- **Deep learning:** TensorFlow, Keras, TensorFlow Datasets, PyTorch
- **Numerical/image processing:** NumPy, SciPy, Pillow
- **Visualization and evaluation:** Matplotlib, pandas, scikit-learn, pycocotools

## Running the Notebooks

Open a project notebook in Colab or Jupyter. Notebooks may download external datasets or require local image/video files. Install the repository dependencies with `pip install -r requirements.txt`.
