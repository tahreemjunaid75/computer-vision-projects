# Computer Vision Course Projects

A comprehensive collection of hands-on projects and implementations covering the progression from foundational image processing techniques to advanced deep learning models in Computer Vision.

## Repository Structure

- **`01-image-segmentation/`** – Pixel-level classification and semantic/instance segmentation models.
- **`02-object-detection/`** – Localizing and identifying multiple objects within images and video streams.
- **`03-transfer-learning/`** – Leveraging pre-trained CNN architectures for custom vision tasks.
- **`04-mnist-classification/`** – Handwritten digit recognition using neural networks and deep learning.
- **`05-classical-cv/`** – Traditional computer vision techniques (filtering, edge detection, feature extraction, and morphological operations).
- **`06-fundamentals/`** – Core concepts of digital images, color spaces, transformations, and basic OpenCV/NumPy operations.

## Tech Stack
* **Language:** Python
* **Libraries:** OpenCV, PyTorch / TensorFlow, NumPy, Matplotlib
